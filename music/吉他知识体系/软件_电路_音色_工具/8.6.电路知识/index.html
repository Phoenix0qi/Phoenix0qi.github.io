      1. 电吉他器件电路

      1.1. 电吉他连接链路

      • High/Low Z 高低阻抗接口
        • 电吉他音箱 / 声卡 输入接口 要阻抗匹配

      1.2. 阻抗匹配

      • 电吉他阻抗匹配

      • 输入阻抗指一个电路从输入端的看过去的等效阻抗，为前级的负载

        • Zin = U / I， 在输入端加 U 测 I
        • 同样的输入电压的情况下（假定电压一定），如果输入阻抗很低，就需要流过较大电流，这就要考验前级的电流输出能力了
        • Rin 越大，后级获取的信号越大，最大化电压传输
        • 后级需要将前级电流信号尽可能放大
        • 结论：后级输入阻抗越大越好，前级输出阻抗越小越好

      • 前级： 吉他 / 乐器

        • 前级前级输出阻抗越小越好

        • 电吉他内部电路

          • 拾音器 == 点源 100mV （切割磁感线发电）
            • 切割磁感线程度，决定电信号大小
            • E=ΔϕΔtE = \frac{\Delta \phi}{\Delta t}E=ΔtΔϕ​
          • 15k 为吉他内部阻抗
          • 1M 为后级电路输入阻抗
          • 需求： 相同线圈产生电压相同下，让后级获得更大的电压（只考虑电阻），最大化输出输出功率 还是 输出电压？
            • U=I(R0+Rin)U = I(R_0 + R_{in})U=I(R0​+Rin​)
              • maxURin,Rinmax U_{R_{in}}, R_{in}maxURin​​,Rin​越大越好
              • maxPRinmax P_{R_{in}}maxPRin​​, 需要 Rin=R0R_{in} = R_0Rin​=R0​ (降低反射能量……)
                • P=(UR0+Rin)2∗RinP = (\frac{U}{R_0 + R_{in}})^2 * R_{in}P=(R0​+Rin​U​)2∗Rin​
                • P=(URin+R02/Rin+2R0)P = (\frac{U}{R_{in} + R_0^2 / R_{in} + 2R_0})P=(Rin​+R02​/Rin​+2R0​U​)
                • maxPRinmax P_{R_{in}}maxPRin​​, 需要 Rin=R0R_{in} = R_0Rin​=R0​
          • 猜测：
            • 最大化URinU_{R_{in}}URin​​而不是PPP，电吉他小信号放大，只需要将吉他产生的U尽可能传导到后级即可，因此后级输入阻抗越大越好。
            • 最大化P，应该在音箱输出，功率尽可能发送到音箱上，降低反射，因此最大化P，阻抗相近匹配。
          • 输入阻抗从低到高，听感上最直接的是音量大小，信号细节放大

        • 其他乐器、麦克风

          • 输出阻抗情况
            • 麦克风： 50Ω - 600Ω，低
            • 吉他、贝斯：>15kΩ, 高
            • 效果器：10kΩ，高，与吉他相近，阻抗匹配

      • 后级： 声卡 / 效果器 / 音箱

        • 后级输入阻抗越大越好

        • UR22C-高阻抗输入部分电路图

          • Hi-Z：输入阻抗提高（1 MΩ），输入阻抗越大，从前级（吉他输出）获得的信号越大

        • 效果器

          • 问题：
            • 输入阻抗不够高：
              • 效果器不一定有这么高的输入阻抗，例如锗晶体Fuzz效果器
              • 如Fuzz Face 的输入阻抗只有10K ohm，10K／（10K＋10K），等于只有一半的讯号进入Fuzz Face，另一半则是耗损在拾音器中。
            • 考虑cable电感
              • 电感拉低输入阻抗
          • 解决方法
            • DI盒

        • 音箱

          • 输入端 同 声卡，有高阻抗输入接口
