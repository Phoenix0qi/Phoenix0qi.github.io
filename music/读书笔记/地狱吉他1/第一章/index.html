      1. 第一章：唤醒指法地狱 左手强化 - 10

      • 概要：

      • 视频：

      1.1. 半音阶爬格子，热身 - 1

      • ✅ 目标速度：160/160

      • ⏱ 内容：半音阶跨弦爬格子练习

      • 📝 目的：热身，提高手指灵活性与准确性

      1.2. 半音阶爬格子，热身 - 2

      • ✅ 目标速度：160/160

      • 与练习 1 相似，结构反转

      • 📝 目的：热身，提高手指灵活性，快速移动准确性

      • 🧩 扩展练习：

        • 更多爬格子组合

      1.3. 蜘蛛爬动

      • ✅ 当前速度：80/100

      • 📝 内容：

        • 加强 无名指 - 小指 控制力
        • 内外侧拨弦

      • 🎯 注意：

        • 高准确性

        • 左手：无名指/小指独立性, 练习 无名指-小指 控制力

        • 右手：拨弦方向控制, 训练内外侧拨弦（乔伊-速度也有）

      1.4. 手指扩张练习

      • ✅ 当前速度：100/115

      • 📝 内容：

        • 手指扩张

      • 🎯 注意：

        • 手指扩展控制
        • 内容：Mi 把位五声音阶

      1.5. 单弦-三音一组pattern - Yngwei风-NeoClassical

      • ✅ 当前速度：140/170

      • 📝 左手击勾弦练习 legato

      • 🎯 要点：

        • 左手食指快速横移

        • 注意只需控制食指移动

        • 和声小调练习（#5 → 6）

      1.6. 双弦 - 加强无名指小指 - Andy Timmons

      • ✅ 当前速度：70/90

      • 📝 内容：

        • 练习：左手 无名指小指 力量+耐力

      • 🎯 要点：

        • 不保留手指

        • Mute：左手食指轻轻抵住

      1.7. 多弦 - 分解和弦 - 拨片控制力

      • ✅ 当前速度：90/90

      • 📝 内容：

        • picking分解和弦

      • 🎯 要点：

      • 练习：右手picking力度，控制位置；左手持续音

      • 演奏内容：基于drop2 3715 变化和弦；

      • 和弦：6m9 - 4M7#11 - #4mb5 - 5M-b7M9

      • 分解和弦琶音曲目：

      1.8. 五声音阶

      • ✅ 当前速度：100/140

      • 📝 内容：

        • 🎼 小调五声音阶（La 把位）

      • 🎯 要点：

        • 小调五声音阶 模进 La把位

      1.9. 大调音阶 - 记忆指板 - 音阶模进

      • ✅ 当前速度：120/135

      • 📝 内容：

        • 🎼 大调音阶

      • 🎯 要点：

        • Block position: Do Re Mi 指形下大调音阶

        • 每根弦3个音，相邻box 去+回

        • 记忆指板-脑子指板地图；音阶模进；

        • 扩展练习：

          • 小调音阶，和声小调，旋律小调：
          • 音阶模进 （乔伊-速度）

      1.10. 把位大风车 大幅移动把位

      • ✅ 当前速度：120/160

      • 📝 内容：

        • 🎼 把位大幅度切换

      • 🎯 要点：

        • 把位大幅度移动；迅速mapping 把位+block+音
        • 弹上一个的同时注意下个要弹的位置
        • 姿势：
